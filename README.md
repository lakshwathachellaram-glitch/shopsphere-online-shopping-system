# ShopSphere – Online Shopping System

## About the Project
ShopSphere is a web-based online shopping application developed using Java and Spring Boot. It provides a user-friendly shopping experience with product browsing, cart management, checkout, user accounts, and order management features.

## Features
- Product listing
- Product search
- Category filtering
- Product details
- Shopping cart management
- Checkout and order placement
- Ratings and reviews
- Wishlist
- Order history
- User login and registration
- Admin dashboard
- Coupons and discounts
- Contact and help page

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- HTML
- CSS
- Maven
- Git & GitHub

## How to Run the Project

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Ensure Java and Maven are installed.
4. Open the terminal inside the project folder.
5. Run:

```bash
.\mvnw.cmd spring-boot:run
```

6. Open your browser and visit:

http://localhost:8080

## Project Purpose
This project was developed to understand Java-based web application development, Spring Boot, MVC architecture, website design, and GitHub version control.
